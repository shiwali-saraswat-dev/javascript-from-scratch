## How this repo works

- One folder per topic, numbered in roadmap order
- Every topic is added through its own pull request (`topic/<folder-name>`)
- Each topic folder has `README.md` (notes), `examples/`, `exercises/` and, where relevant, `mini-project/`
- Progress in the table above is updated in the same PR that completes a topic

## Run the code

- Pure JS files: `node path/to/file.js`
- Browser demos (topics 22 to 25): open `index.html` with the VS Code Live Server extension
